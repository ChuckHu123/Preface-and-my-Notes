# 《我炸了》

他，降生于这个喧嚣的世间，自幼便与"平静"二字无缘。

## 幼年时期

他是一枚安静的火药桶，外表波澜不惊，内心暗流涌动。课堂上，老师的一句提问便能让他颅内烟花盛放；考试时，试卷上那道似曾相识却怎么也想不起来的题目，是他人生中第一次"炸了"。

## 少年时期

他的"炸"愈发炉火纯青。游戏连跪五局，他炸了；食堂最后一份糖醋排骨被人捷足先登，他炸了；精心编辑的消息发给了错误的人，他——炸了。每一次"炸"，都如惊雷裂空，令在场众人无不侧目。朋友们说，他的情绪如同一座活火山，你永远不知道下一次喷发会在何时。

## 青年时期

他试图与"炸"和解。他读了《情绪管理指南》，学了冥想，甚至报名了瑜伽课。然而，当外卖小哥把别人的奶茶送到他手上时，一切修行化为齑粉——他，又炸了。

## 如今

他将"我炸了"升华为一种人生哲学。他不再抗拒，不再压抑，而是坦然拥抱每一次灵魂深处的爆破。因为他终于明白：

> **人生苦短，不如炸得响亮。**

---

他的朋友们为他作传，只用了三个字概括他的一生——

**我炸了。**
